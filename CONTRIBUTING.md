# Contributing to HUR

Thank you for your interest in contributing to HUR!

## How to Contribute

### Adding a Package

1. Fork the repository
2. Create a new branch: `git checkout -b add-my-package`
3. Create your PKGBUILD in `packages/your-package/`
4. Test the package locally
5. Submit a pull request

### Package Structure
```
packages/
└── your-package/
    ├── PKGBUILD
    ├── README.md
    └── .SRCINFO
```

### Writing Guides

1. Create a new file in `wiki/`
2. Follow the template in `wiki/template.md`
3. Submit a pull request

## Guidelines

- Be respectful and inclusive
- Test your contributions
- Follow Arch packaging standards
- Document your work

## Questions?

Open an issue or join our Discord!
