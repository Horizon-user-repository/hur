# Contributing to HUR

Thank you for your interest in contributing to HUR!

## How to Contribute

### Adding a Package

1. Fork the repository
2. Create a new branch: `git checkout -b add-my-package`
3. Create your PKGBUILD in `packages/your-package/`
4. Test the package locally
5. Submit a pull request

### Package Structure
```
packages/
└── your-package/
    ├── PKGBUILD
    ├── README.md
    └── .SRCINFO
```

### Writing Guides

1. Create a new file in `guides/`
2. Follow the template in `guides/template.md`
3. Submit a pull request

## Code of Conduct

- Be respectful and inclusive
- Help others learn and grow
- Give constructive feedback
- Follow community guidelines

## Questions?

Open an issue!
