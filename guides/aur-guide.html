Installing AUR Packages

A guide on using yay and paru to manage packages from the Arch User Repository (AUR) in 2026.

Prerequisites

Before installing an AUR helper, ensure your system is updated and has the necessary build tools:

sudo pacman -Syu base-devel git

1. Installing the Helpers

Since AUR helpers are not in the official repositories, they must be built manually first.

Option A: Installing yay

git clone https://aur.archlinux.org
cd yay
makepkg -si

Option B: Installing paru

git clone https://aur.archlinux.org
cd paru
makepkg -si

2. How to Use yay and paru

Both helpers use syntax nearly identical to pacman. Replace yay with paru depending on your preference.

Action Command
Search for a package yay -Ss [package_name]
Install a package yay -S [package_name]
Update all packages (System + AUR) yay or yay -Syu
Remove a package yay -R [package_name]
Clean unneeded dependencies yay -Yc

3. Which one should I use?

  • yay (Yet Another Yaourt): Written in Go. It is the most popular AUR helper and focuses on a simple, user-friendly interface.
  • paru: Written in Rust. It is developed by a co-maintainer of yay and offers more advanced features like integrated PKGBUILD reviewing.

For more information, visit the official Arch Wiki AUR page.
