Installation Guide

HorizonOS/Arch installation for 2026 focuses on NVMe Gen5 optimization and Secure Boot integration.

Quick Install

# Standard Horizon Bootstrap
curl -sL https://install.horizon.org | bash

For manual users, ensure you use btrfs with zstd compression to save SSD lifecycle.

Kernel Customization

The kernel is the heart of your custom distro. In 2026, we utilize BBR3 for network and Sched-ext for process handling.

# Install Horizon optimized kernel
yay -S linux-horizon-zen
Use modprobed-db to reduce kernel compilation time by only building modules your hardware actually uses.

Build Your Own Distro

To turn your setup into a bootable ISO, use the horizon-iso wrapper for Archiso.

Steps:

  1. Clone the base: git clone https://github.com
  2. Add your custom repo to pacman.conf
  3. Run: sudo mkarchiso -v -o ./output .

Hyprland Mastery

The premier Wayland compositor for 2026. Horizon includes pre-baked End4 dotfiles.

# Start Hyprland with Horizon Config
exec Hyprland --config ~/.config/hypr/horizon.conf

Keybindings: SUPER + Q (Terminal), SUPER + D (Launcher), SUPER + C (Colors).

Visual Branding

Modifying the look of your distro involves three key areas:

  • Plymouth: The boot animation.
  • SDDM: The login screen.
  • Neofetch/Fastfetch: The terminal identity.

Replace assets in /usr/share/horizon/branding/ to update all system logos globally.
