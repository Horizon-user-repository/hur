The Horizon Wiki

Your technical guide to modifying Arch Linux and the HorizonOS ecosystem in 2026.

Note: This wiki is community-maintained. For official Arch upstream documentation, always cross-reference with the Arch Wiki.

1. Installation Core

HorizonOS follows the "Rolling Release" model. While the Horizon Installer script exists, manual installation provides the most control for developers building their own distros.

# Connect to WiFi
iwctl --passphrase YOUR_PASSWORD station wlan0 connect YOUR_SSID

# Verify Boot Mode (UEFI is required for 2026 standards)
ls /sys/firmware/efi/efivars

2. Customizing the Kernel

To make a distro feel "premium," kernel tuning is required. Most HorizonOS users prefer the linux-zen kernel for better desktop responsiveness.

Available Kernels:

  • Linux Mainline: Bleeding edge features.
  • Linux LTS: Maximum stability.
  • Linux Zen: Optimized for gaming and desktop interactivity (Horizon Choice).
  • Linux Hardened: For high-security environments.
# Installing the Zen Kernel
sudo pacman -S linux-zen linux-zen-headers
Warning: Modifying kernel parameters in /etc/default/grub can prevent your system from booting if configured incorrectly. Always keep a Live USB nearby.

3. The Archiso Toolset

The Archiso tool is the heart of distro creation. It allows you to package your entire customized setup into a bootable ISO image.

How to Build a Custom ISO:

  1. Install the profile tool: sudo pacman -S archiso.
  2. Define your package list in packages.x86_64.
  3. Add your custom configuration scripts to airootfs/root/customize_airootfs.sh.
  4. Execute the build script with root privileges.
# Running the build process
sudo mkarchiso -v -w /tmp/archiso-tmp -o ./out ./your_custom_profile/

4. Wayland in 2026

In 2026, Wayland is the default display protocol for HorizonOS. It provides modern features like fractional scaling and HDR support which are essential for high-resolution displays.

To ensure your custom distro works perfectly with Wayland, make sure to include the xdg-desktop-portal-hyprland or xdg-desktop-portal-kde packages depending on your DE choice.
