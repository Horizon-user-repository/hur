Quick Start

Add HUR to Your System

# Add HUR repository
echo "[hur]" | sudo tee -a /etc/pacman.conf
echo "Server = https://yourusername.github.io/hur/repo/\$arch" | sudo tee -a /etc/pacman.conf

# Update package database
sudo pacman -Sy

# Install a package
sudo pacman -S package-name
