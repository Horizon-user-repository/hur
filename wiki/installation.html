Installation Guide

This guide will walk you through installing HorizonOS on your computer.

⚠️ Before You Begin

Installation will erase all data on the selected disk. Make sure to back up important files before proceeding.

Prerequisites

  • HorizonOS ISO file (download from official website)
  • USB drive (4GB or larger)
  • Computer with UEFI/BIOS boot support
  • Internet connection (recommended)

Step 1: Create Bootable USB

Use one of these tools to create a bootable USB:

On Linux:

sudo dd if=horizonos.iso of=/dev/sdX bs=4M status=progress && sync

On Windows:

Use Rufus or Etcher

Step 2: Boot from USB

  1. Insert the USB drive into your computer
  2. Restart your computer
  3. Press the boot menu key (usually F12, F2, or DEL)
  4. Select the USB drive from the boot menu

Step 3: Start Installation

HorizonOS will boot into a live environment with Fenix installer. The installer will launch automatically in Firefox.

Choose Installation Disk

Select the disk where you want to install HorizonOS. All data on this disk will be erased.

Create User Account

  • Enter your username
  • Set a strong password
  • Choose a hostname for your computer

Select Desktop Environment

  • KDE Plasma: Full-featured desktop with extensive customization
  • Hyprland: Tiling window manager for advanced users

Step 4: Wait for Installation

The installation process takes 10-15 minutes depending on your internet speed. Do not turn off your computer during installation.

Step 5: Reboot

Once installation is complete, remove the USB drive and reboot your computer.

Post-Installation

After rebooting, you'll be greeted with the HorizonOS Welcome app where you can:

  • Install additional software
  • Configure system settings
  • Install AUR helpers (yay, paru)
  • Set up gaming tools
  • And much more!
